# Harsh Physiotherapy & Rehabilitation

Static website for GitHub Pages.

## Files
- `index.html` — website homepage
- `dr-harish-banjare-pt.png` — Dr. Harish Banjare (PT) profile photo

## Publish with GitHub Pages
1. Open your repository: https://github.com/harishbanjare124-oss/Harsh-physiotherapy
2. Upload `index.html` and `dr-harish-banjare-pt.png` to the repository root (same folder).
3. Commit the changes to the `main` branch.
4. Open Settings → Pages.
5. Under Build and deployment, select Deploy from a branch, choose `main` and `/ (root)`, then Save.
6. Wait for the Pages deployment to finish. The published URL will appear in Settings → Pages.
